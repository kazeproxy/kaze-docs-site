    授权说明¶

    免费版 / 授权版¶

    免费版 授权版
    每节点有效用户数 100 按授权
    协议 全部 按授权覆盖的协议
    功能 全部 全部

    不填授权就是免费版，协议和功能都不阉割，只限每节点 100 个有效用户：面板不管下发多少人，节点都按用户 ID 从小到大服务前 100 人，其余连不上。

    「有效用户」指有效套餐内、未到期、流量未超、未封禁的用户，以面板下发给节点的名单为准。

    购买¶

    授权在 Telegram 销售机器人 @kaze_auth_bot 里购买、续费、升级、换绑，USDT（TRC20）付款，付款后即时发放。

    • 档位：按协议数量（1 种到全部）× 人数档位（500 / 2000 / 6000 / 不限）× 期限（半年、1 年、2 年、3 年、永久）计价，机器人里选好即显示价格。
    • 升级：人数或协议不够用时在机器人里升级，按剩余时间补差价，节点自动生效。
    • 售后：问题先看常见问题，解决不了用机器人主菜单的「联系客服」，或到频道 @kaze_core 的评论区留言。

    购买须知¶

    • 授权一经发放不退款；买错档位可以在机器人里升级补差价，不能降级。
    • 授权绑定一个面板，该面板下节点数不限；首次绑定 24 小时内可免费换绑一次，之后每次换绑收手续费、每 30 天最多一次。
    • 授权码仅供购买者的面板使用，不得转售；需要转给别人（换号、换人）时联系客服转让。
    • 节点向授权服务器上报的只有授权码、面板域名、节点实例 ID 和用户的脱敏标识（哈希），不含用户 IP、邮箱、流量内容。
    • 授权服务器维护或故障在 @kaze_core 公告；节点手上的租约可撑 3 天。

    授权码¶

    授权码形如 KZ-XXXX-XXXX-XXXX，在机器人购买后即时发放。填法：

    license_key=KZ-XXXX-XXXX-XXXX

    或存成文件：

    license_file=/etc/kaze/license.txt

    一键安装时加 --license KZ-XXXX-XXXX-XXXX，Docker 写在 environment 里。查看授权状态：

    kaze license

    换授权码¶

    已装好的节点换码（换了新码、补填授权码都一样），每台机器一条命令：

    kaze config license_key=KZ-XXXX-XXXX-XXXX && kaze restart

    第二个实例加 -n b：kaze -n b config license_key=... && kaze -n b restart。

    改 Compose 里 environment 的 license_key，然后：

    docker compose up -d

    改 /etc/kaze/kaze.conf 里的 license_key，然后 systemctl restart kaze。

    重启后节点立即签到，kaze license 能看到新码的状态。新码由第一个签到的面板自动绑定，所以多台机器逐台换即可，不用停机；旧码不再使用，可以在机器人「我的授权」里查看或留作备用。

    绑定面板¶

    授权码不用事先填域名：第一个用它对接的面板自动成为绑定面板，之后只有这个面板的节点能用。同一个面板下所有节点共用一个授权码，节点数量不限。

    「同一个面板」按 panel_url 的主机名判断：协议、端口、大小写、末尾斜杠都不算，三台机器只要域名一样就是同一个面板。用 IP 对接会绑到那个 IP，之后改成域名就算另一个面板。

    绑定错了（比如先在测试面板试了一下），首次绑定 24 小时内可以在机器人里免费换绑一次；之后每次换绑收手续费，且每 30 天最多换绑一次。换绑是「解绑」：确认后旧面板的节点最晚 1 小时内失效，下一个用这个授权码对接的面板自动绑定；旧面板不能再把它绑回去。

    面板换域名也算换绑：新域名的节点签到会得到 LICENSE_REFUSED mismatch。顺序是：先在机器人里「换绑」（解绑），再把每台机器 kaze config panel_url=https://新域名 && kaze restart，第一台签到的就把码绑到新域名上。计划换域名时把所有机器一起改，别分几天改。

    节点怎么校验¶

    节点启动时向授权服务器签到一次，拿到一张 3 天有效的租约，之后每 1 小时续一次。续费、升级、换绑都在下一次签到时生效，不用换码、不用重启。

    授权服务器连不上时，节点在手里的租约到期前照常运行（最长 3 天），日志里会提示 LICENSE_SERVER_UNREACHABLE（授权服务器自身证书到期时也会这样回应，节点同样按租约运行）；超过 3 天仍连不上才退回免费版。节点需要能访问 license_server（默认 https://auth.kazecore.dev，开了出站防火墙的机器要放行；一般不用改）。授权服务器维护或故障会在频道 @kaze_core 公告。

    永久授权同样要定期签到，规则一样。

    kaze license 看当前状态，一行：

    LICENSE_OK licence KZ-XXXX-****-****, up to 2000 users, until 2027-04-11 (checked in)

    拒绝时会写原因，例如 LICENSE_REFUSED licence KZ-XXXX-****-**** refused (mismatch): this licence is bound to panel.example.com, not this panel。绑定的面板、到期日、人数在机器人「我的授权」里也能看到。

    到期¶

    到期后不会停机：节点进入 30 天宽限期，每个节点按用户 ID 从小到大保留前 100 人继续服务，其余暂时连不上，日志提示 LICENSE_REFUSED licence KZ-XXXX-****-**** expired on 2026-10-01; running at 100 users per node for 30 days, renew it in the bot。宽限期过后才退回真正的免费版（同样是前 100 人）。

    到期前 7 天、前 1 天和到期当天，机器人会私信提醒（带「续费」按钮），节点日志也有 LICENSE_ENDING_SOON。在机器人里续费后，下一次签到（最长 1 小时）自动恢复；想立即恢复 kaze restart（启动时会签到一次）。

    超出人数¶

    超出授权人数时，已经在用的用户不受影响，只有新来的用户暂时无法连接，日志里有提示。

    • 有人套餐到期或被停用，空出的名额按用户 ID 从小到大让给排队的新用户。
    • 到期后又续费回来的用户，算作新来的：有空位才能接入，不会把正在用的人挤掉。
    • 授权人数变少时（例如授权过期退回免费版），已在用的用户里按 ID 从小到大保留。

    人数按面板下发给节点的用户计算，面板只下发有效用户，所以不会把过期、超流量、被封禁的用户算进去。

    授权服务器会统计一个授权码在 24 小时内实际服务过的不同用户数（按节点上报的脱敏标识汇总，不含用户信息）。超过授权人数的 1.5 倍时，授权方会收到通知并人工核实，节点照常运行，不会因为人数统计自动受限。核实是一个授权码给多个面板共用时，授权方会为这个授权码开启限制：超过 1.1 倍时日志提示 LICENSE_OVER_LIMIT，节点不再接纳新用户；超过 1.5 倍并持续两天，授权服务器拒绝签到。遇到这种情况请在机器人里升级人数档位。

    日志里的授权状态¶

    日志 含义 处理
    LICENSE_OK 授权正常 —
    LICENSE_ENDING_SOON 7 天内到期 机器人里续费
    LICENSE_OVER_LIMIT 授权已被开启人数限制，24 小时内服务的用户超过授权人数的 1.1 倍，节点不再接纳新用户 升级人数档位
    LICENSE_REFUSED 授权码无效（unknown_code）、已过期（expired）、绑定在别的面板（mismatch / moved）、被停用（suspended / revoked）、已开启人数限制且超出 1.5 倍持续两天（over_limit），括号里的词会出现在日志里 按提示在机器人里处理
    free edition ... does not cover 授权不含这个节点的协议，该节点按免费版（100 人）运行 升级授权，或换成授权覆盖的协议
    this build has been modified 程序文件或授权被改动过 重新用一键脚本安装官方版本
    LICENSE_SERVER_UNREACHABLE 连不上授权服务器，先按上次租约运行；租约最长 3 天，按节点实际运行的时间计，改系统时间或重启都不会延长 检查节点出网和 DNS
    LICENSE_LEASE_EXPIRED 3 天没签到成功，退回免费版 同上
    LICENSE_CLOCK_ROLLBACK 系统时间被调回，等待重新签到 校准系统时间
    licence server answer does not match the check-in 授权服务器的回答和节点发出的签到对不上，多半是 license_server 被改到了别的地址或中间有人改写请求 把 license_server 改回默认值
    licence ignored, running as the free edition license_key / license_file 的内容读不出来（格式不对、文件不存在），节点按免费版继续跑，后面的 err= 是原因 检查授权码有没有抄错、文件路径对不对
    local mode runs as the free edition; the licence setting is ignored type=local 不需要授权，填了也不用 删掉授权设置即可

    拿到的是 KAZE1. 开头的离线授权文本（而不是 KZ- 授权码）时，kaze license 的判定语句略有不同：

    输出 含义
    licence KZ-XXXX-****-****, up to 2000 users, valid until 2027-04-11 正常
    ... expires in 9 days on 2026-10-20 14 天内到期
    ... EXPIRED on 2026-10-01, grace period ends 2026-10-08 已到期，离线授权的宽限期是 7 天
    licence KZ-XXXX-****-**** expired on 2026-10-01 宽限期也过了，按免费版运行
    licence KZ-XXXX-****-**** is bound to a.example.com, not b.example.com 授权绑定的面板和 panel_url 不一致
    licence KZ-XXXX-****-**** does not cover vless 授权不含这个节点的协议

    机器人怎么用¶

    销售机器人 @kaze_auth_bot 的命令，每条都对应主菜单里的一个按钮：

    命令 作用
    /start 主菜单
    /buy 购买授权：选协议、人数档位、期限
    /keys 我的授权：查看、续费、升级、换绑
    /recharge 充值余额
    /orders 订单记录
    /help 使用说明
    /price 价目表

    从零到节点跑起来是四步：

    1 购买：「购买授权」里选协议、人数档位、期限，机器人显示价格。余额够就直接「确认支付」。

    2 充值：余额不够时先「充值」。选金额（整数，5 ~ 5000 USDT）后机器人给出一个收款地址和一个带小数的精确金额，用 USDT（TRC20）转账，金额必须一分不差——小数部分就是订单号，改了就对不上。30 分钟内转账，链上确认后 1 ~ 3 分钟自动到账并通知你；没收到可以点「刷新到账状态」。金额填错、对不上订单的转账请联系客服处理。

    3 发码：付款后立即发放授权码 KZ-XXXX-XXXX-XXXX，「我的授权 → 授权码」随时能再看；「安装命令」直接给出带授权码的一键安装命令。

    4 填码：装节点时加 --license KZ-XXXX-XXXX-XXXX，或在已装好的节点上 kaze config license_key=KZ-XXXX-XXXX-XXXX && kaze restart。第一个对接的面板自动绑定，之后 kaze license 能看到状态。

    「我的授权」列出你的每个授权，状态图标： 正常、 7 天内到期、 已过期、 已停用、 已吊销。点开一个授权能看到编号、绑定的面板（还没对接时显示「待绑定」）、协议、人数、到期日，以及近 24 小时服务的用户数和近 7 天在线的节点数。下面的按钮：

    • 授权码 / 安装命令：显示码本身和带码的安装命令。
    • 续费：延长期限，永久授权没有这个按钮。
    • 升级：提高人数档位或增加协议，按剩余时间补差价；已过期的要先续费。
    • 换绑面板：解绑当前面板，下一个对接的面板自动绑上，规则见绑定面板。
    • 从列表删除：只对已吊销的授权显示，把它从列表里清掉。
