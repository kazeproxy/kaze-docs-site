    手动安装¶

    想自己掌控每一步时用这种方式。

    下载程序¶

    curl -fsSL -o /usr/local/bin/kaze \
  https://github.com/kazeproxy/kaze-release/releases/latest/download/kaze-linux-amd64
chmod +x /usr/local/bin/kaze

    curl -fsSL -o /usr/local/bin/kaze \
  https://github.com/kazeproxy/kaze-release/releases/latest/download/kaze-linux-arm64
chmod +x /usr/local/bin/kaze
    校验下载的文件（推荐）

    每个版本都附带 SHA256SUMS，核对一下能确认拿到的是官方构建： 

    cd /tmp
curl -fsSL -O https://github.com/kazeproxy/kaze-release/releases/latest/download/SHA256SUMS
sha256sum /usr/local/bin/kaze
grep kaze-linux SHA256SUMS
    两边的校验值一致即可。

    写配置¶

    mkdir -p /etc/kaze
cat > /etc/kaze/kaze.conf <<'EOF'
type=xboard
node_id=1
panel_url=https://panel.example.com
panel_key=通讯密钥
license_key=KZ-XXXX-XXXX-XXXX
EOF

    license_key 是机器人买到的授权码；没有就去掉这行，按免费版运行。

    对接 V2board

    再加一行 server_type=vless（换成你的协议）。

    检查配置¶

    kaze -c /etc/kaze/kaze.conf -check

    它会连面板拉一次配置和用户，告诉你这个节点会怎么跑，但不监听端口。有问题会直接指出来。

    注册系统服务¶

    /etc/systemd/system/kaze.service
    [Unit]
Description=kaze node
After=network-online.target
Wants=network-online.target

[Service]
User=kaze
Group=kaze
ExecStart=/usr/local/bin/kaze -c /etc/kaze/kaze.conf
Restart=always
RestartSec=3
LimitNOFILE=1048576
AmbientCapabilities=CAP_NET_BIND_SERVICE
NoNewPrivileges=true

[Install]
WantedBy=multi-user.target

    useradd --system --no-create-home --shell /usr/sbin/nologin kaze
chown -R kaze:kaze /etc/kaze && chmod 600 /etc/kaze/kaze.conf
systemctl daemon-reload
systemctl enable --now kaze
systemctl status kaze

    为什么用单独的 kaze 用户

    节点不需要 root 权限。CAP_NET_BIND_SERVICE 让它能监听 443 这类低端口，其它权限一律不给，即使出问题影响也有限。

    一台机器对接多个面板¶

    最简单的是在同一个 kaze.conf 里加一段 [panel b]，一个服务对接两个面板。第一个面板就是文件开头原有的内容，不用改、不用加段落；第二个面板写在 [panel b] 下面。完整文件长这样（见一台机器多个面板）：

    /etc/kaze/kaze.conf
    # 第一个面板：原来的配置原样保留
type=xboard
node_id=1
panel_url=https://a.example.com
panel_key=面板 A 的通讯密钥
license_key=KZ-AAAA-AAAA-AAAA

# 第二个面板：从这里开始是新加的
[panel b]
type=xboard
node_id=7
panel_url=https://b.example.com
panel_key=面板 B 的通讯密钥
license_key=KZ-BBBB-BBBB-BBBB      # 授权按面板算，第二个面板要另一个授权码

    改完 kaze -c /etc/kaze/kaze.conf -check 再 systemctl restart kaze。

    想让两个面板各自独立重启的，也可以跑第二个实例：程序共用一份，配置目录和系统服务各一套，名字加个后缀区分（这里叫 b）。

    mkdir -p /etc/kaze-b
cat > /etc/kaze-b/kaze.conf <<'EOF'
type=xboard
node_id=7
panel_url=https://b.example.com
panel_key=面板 B 的通讯密钥
license_key=KZ-BBBB-BBBB-BBBB      # 授权按面板算，第二个面板要另一个授权码
EOF
chown -R kaze:kaze /etc/kaze-b && chmod 600 /etc/kaze-b/kaze.conf
kaze -c /etc/kaze-b/kaze.conf -check

    服务文件照第一个抄一份，只改名字和配置路径：

    /etc/systemd/system/kaze-b.service
    [Unit]
Description=kaze node (b)
After=network-online.target
Wants=network-online.target

[Service]
User=kaze
Group=kaze
ExecStart=/usr/local/bin/kaze -c /etc/kaze-b/kaze.conf
Restart=always
RestartSec=3
LimitNOFILE=1048576
AmbientCapabilities=CAP_NET_BIND_SERVICE
NoNewPrivileges=true

[Install]
WantedBy=multi-user.target

    systemctl daemon-reload
systemctl enable --now kaze-b
systemctl status kaze-b

    日常管理把 kaze 换成 kaze-b、/etc/kaze 换成 /etc/kaze-b 即可。两个面板互相看不到对方在这台机器上的节点，建节点时端口要错开；升级程序时两个服务都要重启。其他注意事项见一台机器多个面板。

    日常管理¶

    手动安装没有一键脚本带的 kaze 菜单命令（那个菜单脚本装在 /usr/local/bin/kaze，程序本身在 /usr/local/kaze/kaze；手动安装时 /usr/local/bin/kaze 就是程序本身）。文档里的 kaze xxx 对应：

    文档里写的 手动安装时
    kaze restart / kaze status systemctl restart kaze / systemctl status kaze
    kaze log journalctl -u kaze -n 100 --no-pager
    kaze check kaze -c /etc/kaze/kaze.conf -check
    kaze license kaze -c /etc/kaze/kaze.conf -license
    kaze geo kaze -c /etc/kaze/kaze.conf -update-geo
    kaze config 配置项=值 编辑 /etc/kaze/kaze.conf 后 systemctl restart kaze
    kaze update 重新下载二进制覆盖后 systemctl restart kaze
    kaze -reality-keypair 相同（这是程序参数，不经过菜单）
